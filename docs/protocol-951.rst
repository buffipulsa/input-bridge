MCU-951 protocol notes
======================

These notes describe observations from the tested ``0816:2475`` device. They
are not a claim that every similar macropad uses the same protocol.

The complete protocol note is retained in its original Markdown form and is
available as a downloadable file:

* :download:`protocol-951.md <protocol-951.md>`

The generated API documentation is available on the :doc:`api` page. The
protocol note and the implementation documentation should be read together:
the protocol is device-specific and configuration writes require explicit
review.
