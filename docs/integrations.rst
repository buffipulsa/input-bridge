Integrations
============

Input Bridge keeps application-specific setup separate from the core editor
and runtime documentation. These guides describe optional integrations,
profiles, command mappings, and host-application boundaries.

* :download:`Spotify integration guide <integrations/spotify.md>`
* :download:`Maya integration guide <integrations/maya.md>`

The Markdown guides are also linked directly from the project README for
users browsing the repository on GitHub.

Editor feedback
---------------

When the Input Bridge editor is not focused, the transient overlay shows the
active layer and the command submitted by each macropad control. The control
that generated the event also receives a brief blue outline in the editor.
Overlay position and display duration are configurable from Preferences.
